## 五、当前技术债

| 项 | 影响 | 计划 |
|---|---|---|
| `click/longclick/input` 未找到元素时只返回 `ok:false`，无错误码 | 排查困难 | 随 REQ-011 一起改 |
| `scroll` 超过 12 秒静默返回 null | 无明确失败原因 | 随 REQ-011 一起改 |
| 截图在部分 ROM 限流 | 高频截图不稳 | REQ-013 |
| 反连无心跳，靠调用失败判断离线 | 离线感知延迟 | REQ-014 |
| 明文 TCP/HTTP | 仅限可信网络 | 待定 |
